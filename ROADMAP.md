# Roadmap

[Português (Brasil)](ROADMAP.pt-BR.md)

## Version 1 (Windows)

Built in 11 stages, following the build order in the
[scope document](docs/escopo-v1-centavinhos.md). Details of each finished stage
are in [PROGRESSO.md](PROGRESSO.md).

- [x] 1. App foundation: brand, fonts, database, theme, side bar and welcome
  screen
- [x] 2. Accounts, credit cards, categories and tags
- [x] 3. Quick entry
- [x] 4. Month view
- [x] 5. Credit cards: statement month, installments and refunds
- [ ] 6. Monthly recurring entries and next month's total
- [ ] 7. Today's and projected balance, transfers, statement payment
  adjustment and negative balance warning
- [ ] 8. Saved filters and the month view totals
- [ ] 9. PDF report
- [ ] 10. Settings: theme color, light or dark mode, backup and restore
- [ ] 11. MSIX package and Microsoft Store

## After version 1

- Android and iOS, macOS and Linux, reusing the same Flutter code

## Online infrastructure

- Optional account with cloud sync and backup across devices. Version 1 stays
  100% local on purpose.
